# Basics-of-python
### tool : google Colab
### theory : 
In this experiment, we learned the basics of Python programming as an introduction to Exploratory Data Analysis (EDA). The program starts with simple output statements using print() to understand syntax and formatting, including printing on the same line and using multiple statements. We learned how to declare and use variables, understood that Python is case-sensitive, and assigned multiple values to multiple variables.

The experiment covered basic arithmetic operations such as addition, subtraction, multiplication, division, and exponentiation. We also explored different data types in Python like integer, float, string, boolean, and complex numbers using the type() function. User interaction was introduced using the input() function along with type casting to perform calculations.

Practical programs were written for real-life applications such as a simple calculator, total and average marks calculation, area and perimeter of rectangle and circle, and tuple operations. These examples helped in understanding logical thinking and applying Python concepts to solve basic problems.


### conclusion :
This experiment helped us build a strong foundation in Python basics, which is essential for further studies in data analysis and programming. We understood how to write simple Python programs, work with variables and data types, take user input, and perform mathematical computations. Overall, the experiment improved our confidence in writing Python code and prepared us for more advanced concepts in EDA and programming.
